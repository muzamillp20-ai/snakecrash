## 🎮 About the Game

**Mahira Mansha Snake Crash** is an exciting snake game featuring **Muzamill Bhaiya's snake** chasing **Mahira** through 100 challenging levels! 

### 🏆 Win Condition
When Mahira wins: **"Winner Mahira Mansha - Proud of U!"** 💖

### 💀 Lose Condition  
When the snake catches Mahira: **"Muzamill Bhaiya Digested Mahira!"** 🐍

## ✨ Features

- 🎮 **100 Unique Levels** with increasing difficulty
- 🐍 **12 Snake Varieties** - King Cobra, Rock Python, Viper, Anaconda, Black Mamba, Boa Constrictor, Rainbow Snake, Ice Serpent, Fire Snake, Shadow Snake, Golden Python, Emerald Tree Boa
- 🎨 **10 Board Themes** - Jungle, Desert, Ocean, Volcano, Ice, Space, Cave, Garden, Neon City, Ancient Forest
- 🌀 **Wall Passing** - Snakes wrap around through walls
- 📱 **Mobile Friendly** - Touch controls and responsive design
- 🎯 **Default Game Mode** - Free play without obstacles
- 💾 **Progress Saving** - Your unlocked levels are saved locally
- 🏅 **Level Progression** - Unlock new levels as you complete them

## 🚀 Getting Started

### Prerequisites
- Node.js 18+ 
- npm or yarn

### Installation

```bash
# Clone the repository
git clone https://github.com/your-username/mahira-mansha-snake-crash.git

# Navigate to the project
cd mahira-mansha-snake-crash

# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build
```

## 🎮 How to Play

1. **Start the game** from the main menu
2. **Select a level** from the level selection screen
3. **Control the snake** using:
   - Arrow Keys (Desktop)
   - WASD Keys (Desktop)
   - Swipe Gestures (Mobile)
   - On-screen buttons (Mobile)
4. **Eat 👧 (Mahira)** to grow and score points
5. **Avoid hitting yourself** - if the snake touches itself, game over!
6. **Avoid obstacles** on the board
7. **Complete the food target** to win the level
